# AI Translation Helper

This tool translates text into multiple languages using Google's Gemini API.

## Features

- Translate text into 40+ languages
- Formal / Informal tone support
- Built with Gradio UI
- Powered by Gemini 2.0 Flash

## Installation

pip install -r requirements.txt

## Setup

Create .env file

GEMINI_API_KEY=your_api_key_here

## Run

python app.py
